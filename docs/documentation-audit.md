# Documentation audit: 2026-09-23

This is a source-grounded review of the website and web app documentation. It distinguishes repository behavior from product intent. It is not a production penetration test, deployment inspection, legal assessment, or Stripe settlement audit. The root and app READMEs and [architecture guide](architecture.md) now describe observed behavior and link to implementation; the remaining items below require code or operational work.

## Open implementation gaps

### Authorization and data minimization

1. Make non-browser Convex functions internal and enforce caller identity, organization ownership, or scoped guest capabilities within public handlers. The current [organization functions](../webapp/convex/organizations.ts) expose `get`, `getByOwner`, `create`, and `update`; [orders](../webapp/convex/orders.ts) expose live/history/single-order reads, `createOrder`, and `updateStatus`; [`generateUploadUrl`](../webapp/convex/storage.ts) and [Stripe Connect admin actions](../webapp/convex/stripe.ts) are public. Next's [Server Action checks](../webapp/lib/convex/auth.ts) do not protect a caller invoking these Convex functions directly.
2. Return guest-specific data shapes from public queries. [`organizations.get`](../webapp/convex/organizations.ts) returns `ownerId`, `taxId`, and `stripeAccountId`; [`orders.getOrder`](../webapp/convex/orders.ts) retains `email`, `stripePaymentId`, and `stripeSessionId`. The route organization is not matched inside `getOrder`. Guest page RSC filtering alone is narrower than the public Convex API boundary ([pickup page](../webapp/app/pickup/%5BorganizationId%5D/page.tsx)).
3. Remove terminal tokens from client props and URLs after pairing. The [staff page](../webapp/app/staff/%5BorganizationId%5D/page.tsx) supplies the token to [staff shell](../webapp/components/staff/staff-terminal-shell.tsx), which writes it into tab URLs. Define a real revoke-all operation: [`logoutAllDevicesAction`](../webapp/actions/settings-actions.ts) only redirects, and [`signOutAction`](../webapp/actions/auth-actions.ts) deletes only the browser cookie. [Session tokens](../webapp/convex/authQueries.ts) remain valid until expiry.

### Authentication and lifecycle

4. Verify email-change and deletion flows separately from the login OTP path. [`confirmEmailChangeWithOtp`](../webapp/convex/users.ts) validates the OTP but does not check the associated change token's expiry or count OTP failures; [`storeNewEmailOtp`](../webapp/convex/users.ts) is public and accepts a caller-supplied code with a valid change token. Code generation in [custom auth](../webapp/convex/customAuth.ts) and [user mutations](../webapp/convex/users.ts) uses `Math.random`, despite prior documentation calling it cryptographic.
5. Make account deletion complete and testable before promising full erasure. [`cascadeDelete`](../webapp/convex/organizations.ts) omits `staffSessions`; [`confirmAccountDeletion`](../webapp/convex/users.ts) handles the first organization and user but does not explicitly remove auth accounts, other auth tables, or every verification record.
6. Align terminal and guest tracking expiry with the intended product rules. [Proxy cookies](../webapp/proxy.ts) live 30 days, while [terminal records](../webapp/convex/schema.ts) have optional `expiresAt`; [tracker UI](../webapp/components/guest/order-tracker.tsx) expires ten minutes after completion but [query](../webapp/convex/orders.ts) remains available. Document and implement the desired revocation point.

### Payments, accounting, and operational limits

7. Remove or isolate the unverified [`placeOrderAction`](../webapp/actions/order-actions.ts). It calls a [payment placeholder](../webapp/lib/stripe/placeholder.ts), accepts item price/name/total from FormData, and creates an order without Stripe proof. The live guest cart uses the stronger [Checkout Session path](../webapp/components/guest/cart-sheet.tsx).
8. Reconcile actual provider fees and paginate historical exports/stats. [Webhook mutation](../webapp/convex/orders.ts) stores `stripeFee: 0`; [CSV](../webapp/actions/order-actions.ts) substitutes a flat estimate; [`getOrders`](../webapp/convex/orders.ts) caps results at 100. The same capped query feeds the [overview](../webapp/app/%28dashboard%29/dashboard/%5BorganizationId%5D/overview/page.tsx). Monthly invoices and platform reports are product requirements, not current automation ([product](../PRODUCT.md)).
9. Align media limits and validate actual file content if required. [10 MiB helper](../webapp/lib/constants.ts) has an extension fallback, while [Server Actions](../webapp/next.config.ts) accept only 5 MB bodies. The [storage route](../webapp/app/api/storage/%5BstorageId%5D/route.ts) exposes assets with an immutable one-year public cache; decide whether that is appropriate for every stored asset.
10. Replace invalid lint scripts and add explicit CI if desired. The [web app](../webapp/package.json) and [website](../website/package.json) each run `next lint`, which exited 1 locally with “Invalid project directory provided” on 2026-09-23. No checked-in `.github/workflows` was found. The [legacy realtime adapter](../webapp/lib/convex/realtime.ts) is a no-op stub and should not be described as a subscription implementation.

## Verification scope

Source links in this audit point to the implementation to revisit when behavior changes.
